Follow one sentence through an LLM

Type a sentence and watch what a language model does with it, step by step. By the end of the course, you'll understand every step of this.

1 · Split it into tokens

You'll learn this in Lesson 1

A model can't read text, only numbers. So first the sentence is cut into tokens, and each token gets a number.

. Neo cuts text into single letters. Big LLMs like ChatGPT cut it into word pieces, so the same sentence takes far fewer tokens.

2 · Let the tokens look at each other

You'll learn this in Lesson 1

This is attention, the heart of the Transformer. Each token decides which earlier tokens help it understand the sentence.

3 · Guess what comes next

You'll learn this in Lesson 2

After all the layers, the model gives a chance to every possible next token. Temperature decides how boldly it picks.

4 · Learn which answers people prefer

You'll learn this in Lessons 3 and 4

Neo wrote two endings for your sentence. Pick the one you think is better. Real LLMs are tuned using millions of choices like this.

5 · Use a tool instead of guessing

You'll learn this in Lesson 6

A language model only guesses the next token, so it's bad at exact math. An agent knows when to call a tool instead.
